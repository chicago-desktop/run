# Where the pictures come from

Copied from the Windows 95 shell's icon set (chicago-desktop/shell,
`assets/icons/SOURCE.md`): `run` at 32 and 16 px, Microsoft's artwork from
`shell32.dll`, extracted there from the original `.ico` file as RGBA PNG.
This is not part of the module under MIT; the file name is the picture's
name in the pack, `chicago.run:images/run`. The Bash window the command
opens in is the base's, and its picture is the compositor's business.
